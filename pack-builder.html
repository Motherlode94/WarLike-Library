Pack Builder · Library → Engine

Sélectionne des sprites PNG, modèles GLB et scripts pour créer un lot versionné. Les prefabs enregistrés dans Prefab Studio sont repris lorsque disponibles. Chaque ressource est incluse avec son empreinte SHA-256 ; 16 ressources et 32 Mo maximum par lot.

Chargement du catalogue…

Les scripts sont transportés comme fichiers source et ne sont jamais exécutés automatiquement. Les fichiers GLB doivent intégrer les textures/buffers ; les PNG dépassant 256 Ko ne sont pas installables en prefab via ce parcours. L'outil ne récupère pas automatiquement les dépendances déclarées dans les scripts.
